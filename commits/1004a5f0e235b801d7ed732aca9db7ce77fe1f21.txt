message:
Keep leading digits in disc labels
For filenames that start with digits the label now keeps them instead of
falling back to the first letters ("100% Pascal..." -> "100", not "PAS").
Rule: first 3 alphanumeric chars, preferring the leading run; names starting
with a symbol ([BIOS]...) still fall back to the first 3 alphanumerics
anywhere. Applied consistently to compute_label (bash) and the dry-run
python planner.
