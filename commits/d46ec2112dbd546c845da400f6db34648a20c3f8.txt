message:
Detect blank BD-R capacity via 32h(0) format descriptors
READ CAPACITY returns 0 on blank discs (it reports the last address of
the recorded region), so the previous fix detected 0B on a fresh disc.
growisofs formats blank BD-R with the largest 0x32-class descriptor
(bd_r_format in growisofs_mmc.cpp) - the max of the '32h(0): N*2048'
lines in READ FORMAT CAPACITIES is the deterministic usable capacity
(12,088,320 blocks = 24,756,879,360 B, matches non-blank READ CAPACITY).
